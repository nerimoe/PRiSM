## 边界

这不是实际 QQ 群投递或真实硬件验收。没有启动定时自动关机、向真实群发送消息或调用生产设备。测试覆盖迁移后保留的旧设备配置；仅在新逻辑设备中新增、没有旧设备配置映射的控制项未在这次差分中验证。Bot 的旧麻将等待队列仍采用插件原有实现，本次不证明它与网页的持久化座位可以混合上桌。

源码推送不等于 npm 发布。现有 npm 0.1.38 不包含新版 shopCode／QQ 绑定支持，部署 Bot 仍需使用新版源码构建包或另行发布新版 npm 包。
