# 麻将桌正向与负向计费规则评估计划

## 文档性质

本文档用于评估麻将桌在开桌、缺员、补位和离桌时应采用的业务规则。

本文档不是实现方案，不规定数据库结构、接口、Bot 命令、代码模块、定时任务实现方式或开发排期。本文只定义需要比较的经营规则、每种规则的适用计费模式、评估场景和决策标准。业务规则确认后，才应另行编写技术设计与实施计划。

## 真实计费前提

根据 2026-07-17 生产 D1 的只读导出，当前麻将费用不是独立替代基础入场费，而是通过第二条麻将 session 叠加到基础 session：

- 标准日间计费：每 30 分钟 `+6`。
- 雀友四口机：每 30 分钟 `-1`，叠加后为每 30 分钟 `5`。
- 大洋化学八口机：每 30 分钟 `+1.5`，叠加后为每 30 分钟 `7.5`。
- 停止麻将 session 只停止麻将修正费用；玩家的基础入场 session 仍继续。
- 当前初次开桌需要满员。
- 当前有人下桌时，只停止离开者的麻将 session，其他人的麻将 session 继续。
- 当前补位者加入已经开始的桌局时，会立即开始自己的麻将 session。

因此本文把麻将计费分为两种经营模式，分别评估：

### 负向抵扣模式

麻将 session 的金额小于或等于零，其作用是降低基础计费。四口机属于该模式。

主要经营风险是：玩家已经不满足优惠条件，但负数 session 仍然继续，使其持续获得抵扣。

### 正向附加计费模式

麻将 session 的金额大于或等于零，其作用是在基础计费上追加桌位或设备使用费。八口机属于该模式。

主要经营风险是：系统过早停止正数 session，使玩家仍然占用或使用麻将设备，却不再承担附加费用；另一方向的风险是桌局无法继续时仍无限收取附加费，引发公平与收费争议。

同一计费方案在不同时段可能出现正数、负数或零。本文讨论的是店家对一张桌定义的经营模式，不建议系统根据某一时刻命中的价格正负临时改变离桌政策。若一张桌的经营性质确实会随时段改变，应由店家另行确认该桌采用哪一种固定政策。

## 术语和时间定义

为避免把“计费时间”和“缺员倒计时”混为一谈，本文统一使用以下术语。

### 麻将修正 session

绑定到单个玩家的麻将计费区间。它只负责产生负向抵扣或正向附加费，不代表玩家已经结账，也不替代基础入场 session。

### 连续桌局

一张桌从首次满员开桌到最终结束之间的连续经营状态。连续桌局可以短暂缺员并等待补位；在宽限期内补齐时，仍视为同一场桌局，而不是重新开桌。

### 等待开桌

桌子尚未达到规定人数，也从未进入本次连续桌局。等待开桌期间不应存在本次桌局产生的麻将修正 session。

### 游玩中

桌子已经满员并开启连续桌局，当前人数也达到规定人数。

### 补位中

桌子已经开启连续桌局，但后来人数低于规定人数，且桌局尚未被认定结束。

### 缺员宽限计时

缺员宽限计时不是计费规则中的 30 分钟计价单位，也不直接计算金额。它只是决定一场已经开始的桌局可以在人数不足的状态下保留多久。

完整业务定义如下：

1. 只有已经满员开桌的连续桌局，才可能启动缺员宽限计时；初次开桌前的等人不属于缺员宽限。
2. 当游玩中桌局第一次从满员降到未满员时，记录缺员起点 `T0`。
3. 缺员截止时间为 `T0 + N 分钟`，其中 `N` 是店家为该桌确认的经营宽限时间。
4. 宽限期内有人部分补位但仍未满员，不能修改 `T0`，也不能延长截止时间。
5. 宽限期内重新达到满员，取消本次缺员计时，桌局恢复游玩中。
6. 恢复满员后如果再次缺员，才从新的缺员时刻开始新一轮宽限计时。
7. 截止时间到达时必须重新确认桌子仍未满员；若已经满员，则不执行到期动作。
8. 到期动作不能只写成“自动处理”，必须由正向或负向模式分别明确：结束哪些人的麻将修正 session、是否结束整场桌局，以及是否保留等待名单。
9. 系统重启、Bot 重载或短暂故障不能在业务上改变已经承诺给玩家的起点和截止时间；如何保证这一点属于后续实现设计，不在本文展开。

示例：

```text
14:00  四人满员，桌局开始
15:10  一人下桌，人数 3/4，T0 = 15:10
15:15  一人加入，人数仍为 3/4，不重置 T0
15:18  又一人加入，人数恢复 4/4，取消本次计时
16:20  再次有人下桌，从 16:20 开始新的计时
```

示例中“15:15 仍为 3/4”可能发生在多人先后离桌后；部分补位只改变当前人数，不改变本轮缺员最早发生时间。

## 正向与负向都适用的共同规则

以下内容与麻将修正金额的方向无关，应先作为共同业务基础进行评估。

### 共同规则 1：初次满员才开桌

未曾开桌的等待队列只有达到规定人数时，才开启连续桌局，并为首批玩家开始麻将修正 session。

该规则同时适用于正向和负向模式：

- 负向模式避免人数不足时提前获得抵扣。
- 正向模式避免人数不足、尚不能正常游玩时提前收取附加费。

需要确认的问题：不同桌是否始终使用同一个满员人数，还是每张桌单独定义。

### 共同规则 2：区分初次等待和开桌后的补位

“三个人等第四个人首次开桌”与“桌局已经开始后临时缺一人”不是同一状态。

- 初次等待尚未形成连续桌局。
- 开桌后的补位仍可能属于原来的连续桌局。

这一划分使“满员开桌”和“已开桌后允许短暂补位”可以同时成立，而不必把每次换人都解释为整桌重新开始。

### 共同规则 3：部分补位不能续期

如果采用缺员宽限计时，只有恢复满员才能取消计时。人数从 `2/4` 变成 `3/4` 不能重新获得完整的 `N` 分钟。

该规则同时防止：

- 负向桌通过反复进出延长抵扣。
- 正向桌通过反复改变人数拖延桌局最终决定，造成收费边界不清。

### 共同规则 4：异常情况必须有员工裁决

紧急离场、设备故障、玩家失联、替补争议或错误操作不能完全交给同桌玩家决定。无论最终选择哪一种模式，员工都需要有权纠正桌局状态和处理争议。

本文只评估该权力是否必要，不规定员工通过何种界面或命令操作。

### 共同规则 5：收费责任必须在上桌前可见

玩家在上桌前必须知道：

- 初次开桌需要多少人。
- 中途离桌是否可以单方面生效。
- 等待补位期间麻将修正费用是否继续。
- 什么情况下整桌会自动结束。
- 谁可以处理紧急离场。

无法用简短文字向玩家解释的规则，即使数学上正确，也不适合作为默认经营规则。

### 共同规则 6：不能采用“留桌者继续、补位者等满才计费”的混合规则

如果留桌玩家的旧 session 继续，但补位者要等重新满员才开始新 session，会产生按加入顺序区分收费的结果：

- 正向桌中，留桌者继续支付附加费，补位者免费占位等待。
- 负向桌中，留桌者继续获得抵扣，补位者没有同等抵扣。

该规则既没有严格贯彻“未满不产生麻将修正”，也没有贯彻“占位即产生麻将修正”，不建议继续作为候选。

## 负向抵扣模式候选方案

### 负向方案 N1：维持当前行为，不设置结束边界

有人下桌时只停止离开者的负数 session，其他人继续获得抵扣；补位者加入后立即开始负数 session。桌局不因长期缺员自动结束。

优点：

- 操作最少。
- 玩家短暂等人时持续享受原有抵扣。
- 补位者与留桌者都从自己登记占位时开始获得抵扣。

风险：

- 缺员可能无限持续，优惠条件已经不完整但负数抵扣仍继续。
- 没有明确的最大优惠暴露时间。
- 店员需要主动发现并处理长期缺员。

评估定位：作为现状基线，不建议在没有监控数据的情况下直接认定其可长期保留。

### 负向方案 N2：缺员宽限期内继续抵扣，到期结束整桌抵扣

桌局缺员后启动前文定义的缺员宽限计时。在宽限期内：

- 留桌玩家的负数 session 继续。
- 补位者加入仍未结束的连续桌局后，立即开始自己的负数 session。
- 部分补位不重置截止时间。
- 恢复满员后取消本轮计时。

到期仍未满时：

- 停止该桌所有仍在进行的负数麻将 session。
- 结束本场连续桌局。
- 原有基础入场 session 继续。
- 后续玩家必须重新凑满规定人数，才能开启新的连续桌局和新的负数 session。

优点：

- 为负数优惠设置明确的最大额外暴露时间。
- 正常快速补位不会切断所有人的账单区间。
- 规则可以简单解释为“缺员后保留 N 分钟优惠，补不满则整桌优惠结束”。

风险：

- 宽限期内仍存在人数不足但继续获得抵扣的情况。
- 补位者在未恢复满员前也可能短暂获得抵扣，但该风险被同一个截止时间限制。
- `N` 太长会放大优惠损失，太短会让正常找人补位困难。

评估重点：分别试算 `5`、`10`、`15` 分钟对最大抵扣金额和正常补位成功率的影响。

### 负向方案 N3：一旦缺员立即停止整桌抵扣

任意玩家下桌后，立即停止该桌所有负数麻将 session。桌位可以继续保留等待补位，但只有重新满员时才为当时的全部玩家开始新的负数 session。

优点：

- 负数抵扣只在满员时存在，经济语义最严格。
- 不存在缺员期间继续获得优惠的问题。
- 不需要决定负数优惠宽限期内允许损失多少。

风险：

- 一次短暂离席会切断所有人的抵扣区间。
- 正常补位也会产生多段 session，玩家可能认为过于苛刻。
- 玩家可能因为几分钟的临时缺员失去一整个计价单位中的部分优惠，具体感受需要结合当前取整规则试算。

评估定位：适合作为“优惠资格必须实时满员”的严格候选，与 N2 做经营体验对比。

### 负向模式不建议使用：离开者继续挂账直到完成交接

在负向模式下，继续保留离开者的麻将 session 等于继续给离开者优惠。若其离开麻将桌后去玩音游，该规则正好奖励了不完成交接的行为，因此不应把座位责任制直接用于负向抵扣桌。

## 正向附加计费模式候选方案

### 正向方案 P1：按登记占位时间计费，允许直接下桌

有人下桌时只停止离开者的正数 session；留桌玩家继续承担附加费。补位者加入已经开始的连续桌局后立即开始自己的正数 session。

如果找不到补位者，留桌玩家需要决定是否继续保留桌位；整桌不应在无人知情的情况下无限保持，但是否设置自动结束时间需要单独确认。

优点：

- 每个人按自己的登记占位时长承担附加费。
- 补位者不会免费等待，而留桌者持续付费。
- 系统不会因为一人登记下桌就自动替其他实际使用者停止正向附加费。

风险：

- 留桌者可能在无法正常游玩期间继续支付附加费。
- 找不到补位者时，谁有权结束整桌需要明确。
- 如果只允许每个人结束自己，剩余玩家可能陷入继续收费但无法游玩的状态。

评估重点：店内是否把缺员等待解释为“仍在保留并占用桌位”，以及玩家能否接受该解释。

### 正向方案 P2：座位交接责任制

正向桌开桌后，普通离桌被解释为申请交接，而不是立即停止计费。

业务规则为：

- 离开者提出离桌意愿后，在替补完成交接前仍是该座位的费用责任人。
- 替补必须能够立即接替该座位。
- 留桌玩家需要确认替补能够接入当前桌局；是否要求一人确认、多数确认或全员确认，是本方案的待评估项。
- 完成交接时，离开者停止正数 session，替补者从同一交接时刻开始正数 session。
- 没有替补时，原责任继续，除非整桌结束或员工处理异常。

优点：

- 找不到替补或替补迟到的成本不会转嫁给留桌玩家。
- 正向附加费不会因单方面登记下桌而被提前规避。
- 交接时刻明确，避免同一座位出现无人承担或两人同时承担费用。

风险：

- 其他玩家可能拒绝交接，使离开者承担不可控的持续费用。
- 全员逐个确认操作成本高，也容易形成僵局。
- 紧急离场必须允许员工裁决，不能把账单无限交给其他玩家控制。
- 必须在开桌前明确告知责任，否则容易产生收费争议。

评估重点：

- 是否真的需要剩余所有人同意，还是一名留桌玩家确认已经足够。
- 是否需要设置最长责任时间或仅保留员工例外。
- 玩家是否愿意接受“上桌即承担补位责任”的店规。

### 正向方案 P3：缺员时立即停止整桌附加费，满员后重开

有人下桌后立即停止整桌所有正数 session。桌子可以保留等待补位；重新满员后，再为当时的全部玩家同时开始新的正数 session。

优点：

- 无法正常满员游玩时不继续收取麻将附加费。
- 全体玩家在同一时刻开始新的正数计费，不因补位顺序产生差异。
- “满员才产生麻将附加费”的语义最严格。

风险：

- 四人可以实际继续游玩，却让其中一人在系统中登记下桌，从而停止全桌附加费。
- 每次短暂离席都会切断全体账单区间。
- 没有外部在场验证时，系统无法判断登记缺员是否真实。

评估定位：只有当店内愿意承担更强现场监督，且明确把附加费定义为“满员实际游玩费”时才适用。

### 正向方案 P4：缺员宽限计时只用于提醒或升级处理

正向模式也可以使用前文定义的 `T0 + N`，但到期动作不自动停止正数 session，而是把桌局升级为需要明确决定的异常状态。

在经营层面可评估的到期结果包括：

- 要求留桌玩家明确选择继续保留桌位或结束整桌。
- 通知员工介入确认。
- 按已经事先公布的规则继续由现有座位责任人承担费用。

优点：

- 给“找不到补位者”设置了明确的关注时点。
- 不会因为自动停止正数 session 而直接产生规避附加费的空间。

风险：

- 如果到期后仍然没有明确责任人，问题只是被延后，并未解决。
- 需要一定人工沟通，不如负向模式的自动结束简单。

评估定位：可作为 P1 或 P2 的辅助经营规则，不是独立的收费政策。

### 正向模式不建议直接使用：缺员到期自动结束全部正数 session

如果玩家仍实际使用桌子，自动结束全部正数 session 会使附加费消失。除非店内能够确认桌子确实停止使用，否则该规则会创造比继续计费更直接的套利方向。

## 跨模式组合方案

最终政策不必从所有候选中只选一个。更合理的评估方式是先确认共同规则，再分别为两种经营模式选择到期动作。

### 组合方案 M1：统一连续桌局，按模式处理缺员

共同部分：

- 初次满员开桌。
- 开桌后形成连续桌局。
- 缺员进入补位中。
- 补位者加入未结束桌局后立即开始自己的麻将修正 session。
- 部分补位不延长缺员起点。
- 员工可以处理异常。

负向桌采用 N2：缺员宽限到期仍未满，结束整桌抵扣。

正向桌在 P1 和 P2 之间选择：按占位时间允许直接下桌，或要求完成座位交接；正向桌不因缺员计时自动停止全部附加费。

优点：

- 两种模式共享容易理解的桌局生命周期。
- 只在经济激励真正相反的离桌责任上分开。
- 可以保留当前即时补位体验。

风险：

- 正向桌和负向桌的最终离桌后果不同，必须向玩家明确展示。
- 正向桌仍需要店内确认 P1 与 P2 哪个更符合实际经营习惯。

### 组合方案 M2：所有桌严格满员才产生麻将修正

共同采用 N3/P3：任意缺员立即停止整桌麻将修正 session，重新满员后全员重开。

优点：规则最统一，满员语义最严格。

风险：正向桌容易通过登记缺员规避附加费，账单区间也会频繁切割。该组合只有在店内能够可靠确认实际在场人员时才值得保留。

### 组合方案 M3：保持当前行为，仅对负向桌增加上限

正向桌完全保留 P1；负向桌从 N1 改为 N2。除此之外不增加座位交接或外部确认。

优点：相对当前经营习惯变化最小。

风险：正向桌找不到补位时的收费争议仍由店内临时处理，没有形成更明确的离桌责任。

## 外部验证作为后备方案

MWPT 名单、店员确认、动态二维码或其他现场信号，可以用于核对实际在桌人员。该类方案同时可能服务正向和负向模式，但解决的问题不同：

- 对负向模式，用于证明玩家仍然符合抵扣资格。
- 对正向模式，用于防止玩家通过虚假登记下桌规避附加费。

外部验证的操作和系统成本明显更高。四人面对面麻将本身已有较强互相监督，当前应先评估简单规则是否足够。只有真实运营中持续出现登记状态与现场状态不一致，并造成可量化损失时，才进入外部验证评估。

## 必测经营场景

每个场景必须分别代入负向四口机和正向八口机，不能用一个结果代替两种模式。

### 两种模式共同测试

1. 初始三人等待，第四人在两分钟后到场。
2. 已开桌后离开一人，两分钟内完成补位。
3. 已开桌后离开两人，两名替补先后到场。
4. 缺员后有部分补位，但始终未恢复满员。
5. 桌局恢复满员后再次缺员，确认是否开始新一轮宽限。
6. 玩家因紧急情况、设备故障或网络问题无法正常操作。
7. 店员需要纠正错误的离桌或补位记录。

### 负向模式额外测试

1. 缺员后直到 `N` 分钟到期都无人补位。
2. 玩家在到期前反复加入和退出，但从未恢复满员。
3. 补位者在截止前一分钟加入但仍未补满。
4. 分别用 `5`、`10`、`15` 分钟试算最大额外抵扣。
5. 短暂缺员造成多个负数 session 区间时，玩家能否理解账单。

### 正向模式额外测试

1. 离开者找不到替补，留桌玩家仍希望继续。
2. 替补已经答应，但迟迟未完成实际交接。
3. 留桌玩家拒绝某个替补人选。
4. 离开者发生紧急情况，无法继续承担座位责任。
5. 玩家登记下桌但仍实际留在桌上游玩。
6. 如果采用全员同意，出现一人失联或拒绝确认时如何结束僵局。
7. 等待补位期间继续收取正向附加费，玩家是否认为这是桌位保留费。

## 每个场景的记录模板

评估时应使用同一个记录模板，避免只凭直觉比较：

- 计费模式：正向 / 负向。
- 桌局状态变化：等待开桌 / 游玩中 / 补位中 / 已结束。
- 缺员起点 `T0`、截止时间和是否曾恢复满员。
- 每位玩家麻将修正 session 的开始与停止时刻。
- 等待期间产生的正向附加费或负向抵扣金额。
- 谁需要执行操作，操作次数是多少。
- 是否需要员工介入。
- 最坏情况下可能多收或少收多少。
- 玩家是否可以用一句话理解该结果。
- 是否存在通过虚假登记、延迟交接或反复补位获利的方向。

## 评估标准

### 两种模式共同标准

1. **可解释性**：规则能否在上桌前清楚告知。
2. **一致性**：同一桌的相同状态是否始终产生相同结果。
3. **操作成本**：正常补位是否需要过多确认。
4. **异常处理**：员工能否终止僵局和纠正错误。
5. **审计性**：争议发生时能否说明关键决定和时间边界。

### 负向模式重点标准

1. 优惠资格不完整时，额外抵扣是否存在明确上限。
2. 部分补位是否可能延长抵扣时间。
3. 严格停止优惠是否会显著伤害正常补位体验。

### 正向模式重点标准

1. 玩家实际占用桌位时，附加费是否会被过早停止。
2. 无法继续游玩时，是否可能无限向留桌者或离开者收费。
3. 座位责任是否由本人事先知情并接受。
4. 其他玩家是否拥有过大的账单控制权。

## 当前最值得优先评估的组合

本文不直接决定最终政策，但根据当前讨论，建议优先对组合方案 M1 进行经营推演：

### 两种模式共同采用

- 初次满员才开桌。
- 开桌后形成连续桌局。
- 缺员后进入补位状态，不把每次换人都视为重新开桌。
- 补位者加入尚未结束的桌局后立即开始自己的麻将修正 session。
- 部分补位不能重置缺员起点。
- 员工可以处理异常。

### 负向抵扣桌优先评估

- 采用 N2。
- 缺员宽限期内继续抵扣。
- 到期仍未满则结束整桌负数 session。
- 对 `5`、`10`、`15` 分钟进行金额与体验对比。

### 正向附加计费桌优先评估

- 对比 P1 与 P2。
- P1 代表简单的按占位时间计费。
- P2 代表更严格的座位交接责任。
- P4 可以作为两者的提醒和员工升级机制，但不能替代离桌责任规则本身。

MWPT 或其他外部验证暂不作为首选。只有简单规则在真实运营中出现持续、可量化的滥用后，才继续评估。

## 评估输出

完成桌面推演后，应形成一份业务决策记录，至少确认：

- 每张桌属于正向附加计费模式还是负向抵扣模式。
- 两种模式共同采用哪些桌局生命周期规则。
- 负向桌采用 N1、N2 还是 N3。
- 若采用 N2，`N` 的具体值是多少。
- 正向桌采用 P1、P2 还是 P3，是否附加 P4。
- 正向桌由谁确认交接，是否存在最长责任边界。
- 谁可以结束整桌和处理紧急离场。
- 玩家上桌前必须看到的收费说明。
- 哪些真实指标出现后才值得引入外部验证。

在上述业务决策完成前，不进入技术实现设计。
